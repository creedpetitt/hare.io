# hare.io

A modular, autonomous agent framework designed for, browser automation, and safe local development tasks.

## High-Level Vision
- **The Brain:** A strict TypeScript-based agent loop using LLMs (Claude/GPT).
- **Tooling:** Integrated Playwright for web scraping and network interception.
- **Safety:** Permission-gated local file system and terminal access.
- **Connectivity:** Modular gateways for Discord, Telegram, and CLI interaction.

## Tech Stack
- TypeScript (Strict Mode)
- Node.js
- Playwright
- Zod (Runtime Validation)
- Express (Dashboard API)
