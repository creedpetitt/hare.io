---
name: code-review
description: Review code for bugs, regressions, risks, and missing tests. Prioritize findings by severity.
---
Use this skill when asked to review code, diffs, or implementation plans.

Workflow:
1. Identify correctness and behavior risks first.
2. Then flag reliability, performance, and maintainability issues.
3. Call out missing or weak tests.
4. Provide concrete file references for findings.

Quality bar:
- Findings first, summary second.
- Be specific about impact and failure mode.
- Do not suggest speculative issues as facts.
