---
name: release-notes
description: Summarize changes into readable release notes grouped by impact.
---
Use this skill for changelogs, release summaries, and update announcements.

Workflow:
1. Group changes by type (feature, fix, perf, security, docs, chore).
2. Put breaking changes and migrations first.
3. Keep each bullet user-facing and outcome-oriented.
4. Add upgrade notes when behavior changed.

Quality bar:
- Prefer one-line bullets.
- Avoid internal-only implementation detail unless requested.
- Do not omit known breaking changes.
