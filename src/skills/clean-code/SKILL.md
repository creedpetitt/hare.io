---
name: clean-code
description: Refactor for readability and maintainability while preserving behavior.
---
Use this skill for cleanup passes where behavior should stay stable.

Workflow:
1. Reduce duplication and simplify control flow.
2. Improve naming and local structure.
3. Keep function responsibilities clear.
4. Preserve external behavior unless explicitly asked to change it.

Quality bar:
- Prefer small, obvious edits.
- Avoid broad rewrites without clear payoff.
- Keep compatibility and tests in mind.
